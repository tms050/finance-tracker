# finance-tracker

Трекер личных финансов с парсингом банковских выписок.

## Цель
Создать инструмент для контроля за своими финансами с возможностью загрузки выписки с транзакциями из приложения банка

**Статус:** v1 (MVP) в разработке.

## Возможности

### v1 (текущая версия)
- Парсинг PDF-выписок Сбербанка.
- Сохранение транзакций в SQLite.
- Дедупликация на основе хеша транзакции и периода выписки.
- Отметка транзакций как перевод между своими счетами.
- Просмотр списка транзакций.
- Общая статистика: расходы и доходы.

## Стек

- Python 3.14.3
- pdfplumber - парсинг PDF
- pandas - обработка данных
- SQLAlchemy - ORM
- SQLite (v1)
- Streamlit - веб-интерфейс
- pytest - тесты

## Требования к выписке

- PDF **с текстовым слоем** (не скан/фото). Проверка: откройте файл и попробуйте выделить текст.
- Выписка **Сбербанка**, оформленная через приложение или веб-версию (формат на 01.10.2026).
- Период - любой, но не более одного счёта за раз.

## Известные ограничения (v1)

- Поддерживается только Сбербанк. Другие банки - в планах.
- `counterparty_name` извлекается по известным примерам; на необычных описаниях может быть `None`.
- Сверка баланса ловит арифметические расхождения, но **не** ошибки распознавания, если они внутренне согласованы.
- PDF без текстового слоя (сканы) не поддерживаются.
- Парсер ориентирован на выписки Сбера, оформленные через приложение/веб (формат на **01.10.2026**). При изменении верстки банка возможны сбои в определении координат колонок (парсер свалится в `default layout` и выдаст предупреждения).

## Приватность

Приложение работает **локально**. Выписки, база и транзакции не покидают вашу машину. Телеметрии и внешних API нет.
