# finance-tracker

Трекер личных финансов с парсингом банковских выписок.

## Цель
Создать инструмент для контроля за своими финансами с возможностью загрузки выписки с транзакциями из приложения банка

**Статус:** v1 (MVP) в разработке.

## Возможности

### v1 (текущая версия)
- Парсинг PDF-выписок Сбербанка.
- Сохранение транзакций в SQLite.
- Дедупликация на основе хеша транзакции и периода выписки.
- Отметка транзакций как перевод между своими счетами.
- Просмотр списка транзакций.
- Общая статистика: расходы и доходы.

## Стек

- Python 3.14.3
- pandas - обработка данных
- SQLAlchemy - ORM
- SQLite (v1)
- Streamlit - веб-интерфейс
- pytest - тесты
