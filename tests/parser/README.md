# Тесты парсера выписок

Набор тестов для `src/parser` (Сбербанк). Разделен на три уровня изоляции, чтобы обеспечить быструю обратную связь при разработке и проверку реального поведения на файлах.

## Запуск

Запустить все тесты:
```bash
pytest tests/
```
Только быстрые тесты (без чтения PDF):

```bash
pytest tests/test_sber_pdf_pure.py tests/test_sber_pdf_exact.py
```

С покрытием:

```bash
pytest --cov=parser.sber_parser tests/
```

## Структура тестов

`test_sber_pdf_pure.py` (Unit)

Самые быстрые тесты. Не требуют реальных PDF:
- Парсинг дат, времени, сумм и валют (amount.py, dates.py).
- Валидация конфигураций и раскладок колонок (config.py).
- Контракты датаклассов и сериализация в JSON (models.py).
- Извлечение контрагента из строки описания (_normalize).

`test_sber_pdf_exact.py` (Точные)
Тестируют логику извлечения на заранее подготовленных словах/строках (имитация вывода pdfplumber.extract_words). Позволяют точечно проверить алгоритмы поиска заголовков, границ колонок и склейки строк без открытия тяжелых PDF-файлов.

`test_sber_pdf_integration.py` (Интеграционные)
Тесты полного цикла (end-to-end). Открывают реальные PDF-файлы из папки с фикстурами и проверяют итоговый ParseResult (сверку баланса, количество транзакций, извлеченные метаданные).

## Фикстуры
conftest.py содержит общие фикстуры, доступные во всех тестах:
- parser - готовый экземпляр SberStatementParser с дефолтным конфигом.
